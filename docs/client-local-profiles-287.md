# Local offline profiles

Candidate 01.000.287 adds a local profile to the Accounts page. Choose Create
Offline Profile, enter 1–16 letters, numbers or underscores, and confirm with
Done. The controller keyboard supports this flow. Use Offline Profile selects
the saved name. Edit Offline Username changes it and selects the local profile.

Create or open an instance and choose Download & Play or Play. The existing
publisher download, checksum, cancellation and repair mechanisms provide missing
files without Microsoft authentication. Downloading requires internet access.
An installed instance can launch using its verified cache while offline.

The local player UUID comes from Minecraft's OfflinePlayer username convention.
The chosen name and mode are saved in the library settings. Changing the username
changes the UUID, which can affect inventories and server permissions. A local
profile supports singleplayer and servers configured for offline mode. Servers
requiring Microsoft authentication need the Microsoft account option.

Use Microsoft Account returns to a valid session already in memory or starts
sign-in. Signing in selects the authenticated profile. Starting the launcher with
the offline profile selected skips automatic Microsoft refresh.
