## Dedicated servers in early beta

Host a Vanilla Minecraft Java 26.x world on your PS5 for players on the same network. Turn on **Server [BETA]** in Settings to show the Servers tab, now between Instances and Settings. Both Settings and Servers have larger text and controls for TV use.

- Scan the Servers QR code or open the browser address shown on your PS5, then enter the pairing code. From the browser you can pick a version, accept the EULA, start the server, cancel setup, save and stop, or return to the launcher. Join using the Minecraft address shown on the Servers screen, with a copy button in the browser.
- See live status, player names and count, and uptime. The browser also shows the last 50 console lines and supports a limited set of Minecraft admin commands.
- Edit the server name, player limit, game mode, difficulty, view and simulation distance, PvP, and whitelist in the browser while the server is stopped. Changes apply on the next start.

## Launcher and uploads

- Hold **X** to save and stop a server, confirm instance deletion, or confirm an uninstall. The progress indicator shows when the action will confirm. Mouse clicks and Enter still confirm immediately.
- A **HOSTING** badge and dimmed tabs show when the server has control. Success and error messages appear as notifications, and downloads show transfer speed and estimated time remaining.
- Drag and drop files into browser uploads and track progress separately for each file.

## Bug fixes
