### Added

- Enable or disable installed mods without uninstalling them.
- See each mod’s enabled state in the Installed list, including manually added mods.

### Using the mod toggle

Open Instance Settings → Mods → Installed, select a mod and press X to enable or disable it. RIGHT still opens Uninstall.

Disabled mods stay on your console. If another enabled mod needs one, the launcher tells you which dependency to enable instead of downloading it again. Disabling Controlify also disables its in-game controller support until you enable it again.

Download PPSA99874.zip to install or update ProsperoCraft. Checksums, validation records and the corresponding source and OpenAL relink kit are included.
