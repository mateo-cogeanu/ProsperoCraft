# ProsperoCraft 01.000.265

Prepared release notes. Exact build 265 awaits physical-console confirmation.

## What's new

- Added Vanilla support for Minecraft 1.21 through 1.21.8.
- Added Fabric support for Minecraft 1.21.7 through 1.21.11.
- Fabric 1.21 through 1.21.6 is available as Experimental.
- Controlify is installed by default for new Fabric instances and can be uninstalled.
- Improved Controlify compatibility and fixed YACL dependency selection for 1.21.9.
- Bug fixes.
