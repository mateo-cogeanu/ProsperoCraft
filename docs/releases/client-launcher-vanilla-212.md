# ProsperoCraft 01.000.212

## Changes

- Add Minecraft1.21.10 and1.21.11 Vanilla play with matched native libraries. Earlier1.21 releases and all1.21Fabric remain unavailable.
- Make the launcher smoother with a120Hz presentation target, animated horizontal page/tab changes, themed navigation arrows and continuous selector scrolling.
- Open instances with an expanding card animation and a matching return transition. Remove the extra dark transition layer reported as a brief black flash.
- Open selectors over their dimmed original screen. Preview themes immediately on hover/controller focus, save on confirmation, and restore on Cancel.
- Show all32 instance icons in a larger grid. Replace Modrinth and CurseForge logos with original Amethyst and Compass artwork while preserving saved icon IDs.
- Add stronger localized adaptive L2/R2 page detents, respecting Vibration preference and releasing effects on handoff/exit.
- Honor the selected game resolution for Zink instances, make launcher keyboard action buttons reachable, and preserve navigation/startup notices during saved-account refresh.
- Retain existing26.x Vanilla/Fabric paths, shader/quit/save repairs, Microsoft sign-in, content browsing, uploads, controls and game audio.

## Validation and compatibility

The physical tester accepts the exact212 launcher and explicitly requests this release. Published app bytes match the tested212-final package; no rebuild. Local host checks, native sanitizer/JNI tests, rendered previews, signed integrity and independent package audits pass. Matching OpenAL corresponding source/relink materials and checksums accompany the app.

120Hz is a presentation target; numeric FPS was not measured on console. This acceptance does not establish an exhaustive game, shader, mod, device or endurance matrix. Earlier202 shader/quit confirmation and204 functional acceptance remain scoped historical evidence; no new212 shader pack/profile measurement is claimed.1.21Fabric remains deferred until the Vanilla series is validated. Compatibility depends on matching game, loader, mod and shader versions.

Java Edition ownership is required. Original game/mod JARs and game asset objects are not included; verified originals download on console. Existing instances, settings and worlds remain in writable storage. Client and server share a title ID, so installing one replaces the other. ProsperoCraft is unofficial and is not affiliated with Mojang, Microsoft or Sony.
