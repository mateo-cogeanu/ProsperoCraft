### Added

- Create a local offline profile with a username in Accounts.
- Download Minecraft instances without Microsoft sign-in.
- Play singleplayer or join servers configured for offline mode using your local profile.
- Switch between your saved offline profile and Microsoft account.

### Using offline profiles

Open Accounts, choose Create Offline Profile and enter a username. Then create or open an instance and choose Download & Play. Downloading missing files requires internet access. Installed instances can reuse verified files while offline.

Changing the offline username changes your player identity. Use your Microsoft account for servers that require authentication.

Download PPSA99874.zip to install or update ProsperoCraft. Checksums, validation records and the corresponding source and OpenAL relink kit are included.
