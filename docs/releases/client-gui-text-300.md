### Bug fixes

- Fixed flickering text in Minecraft 1.21 and 1.21.1, including the title, Languages, and Resource Packs menus.
- Defaulted Controlify's on-screen button guides off on Fabric 1.21 and 1.21.1 to prevent flickering controller glyphs.
- Improved installation and memory handling for large Fabric mods such as Cobblemon.

The text fix and shader rendering were confirmed on PS5 with this build.

Download PPSA99874.zip to install or update ProsperoCraft. Checksums, validation records, corresponding source and the OpenAL relink kit are included with the release.
