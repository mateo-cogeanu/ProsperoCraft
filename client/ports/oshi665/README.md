# OSHI6.6.5 PS5 CPU provider

Genuine pinned OSHI6.6.5 SystemInfo dispatch and the original publisher interfaces.
The source pin, SHA-256 and MIT license are in sources.json and LICENSE. This
separate overlay precedes the intact publisher JAR only in the matching game owner.
PS5 reports the existing UNKNOWN platform, with real startup CPU identity and
OS-visible logical count. Other hardware/OS metrics throw; desktop factory selection
is retained. No operating-system spoof or JNA dispatch initialization is needed for
Minecraft1.21.10 GLX CPU text. Physical-console behavior remains pending.

Build with tools/build_oshi665_platform.py, supplying --publisher-cache,
--cache-dir, --output-dir and optionally --java-home/--fetch-deps. Only explicitly
verified publisher dependencies are used. tools/test_oshi665_platform.py checks the
original game CPU entry, missing identity, original desktop selection and provenance.
These manual publisher checks are outside portable host CI.
